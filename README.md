# Smart Shop - Modern E-Commerce Platform

## Overview
Smart Shop is a modern e-commerce platform built with Next.js 14, featuring a beautiful UI and robust functionality. The platform combines cutting-edge technologies to deliver a seamless shopping experience.

## Tech Stack
- **Frontend Framework**: Next.js 14
- **Styling**: Tailwind CSS, GSAP, Framer Motion, AOS
- **Authentication**:  Supabase Auth
- **Database**: Prisma with Supabase
- **UI Components**: Radix UI
- **Form Handling**: React Hook Form
- **3D Graphics**: React Three Fiber, Drei
- **Maps Integration**: React Google Maps API
- **Animation Libraries**: 
  - GSAP
  - Framer Motion
  - AOS (Animate on Scroll)
  - React Spring

## Key Features
- Modern and responsive UI design
- Secure authentication system
- Interactive 3D product visualization
- Smooth animations and transitions
- Google Maps integration
- Real-time data updates
- Dark/Light theme support
- Form validation and handling
- Carousel and interactive components
- Optimized for performance

## Project Structure
```
src/
├── actions/       # Server actions
├── app/          # Next.js app router pages
├── components/   # Reusable UI components
├── contexts/     # React context providers
├── hooks/        # Custom React hooks
├── lib/          # Utility libraries
├── styles/       # Global styles
└── utils/        # Helper functions
```

## Getting Started

1. Clone the repository
2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
- Create a `.env` file with necessary credentials
- Configure Supabase and Kinde Auth settings

4. Run the development server:
```bash
npm run dev
```
